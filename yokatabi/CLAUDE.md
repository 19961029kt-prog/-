# Q-TRIP 九州よりみちダイス — プロジェクトガイド

副題：**KYUSHU ROUTES & ROOTS**　〜サイコロ片手に巡る、ローカル美食と秘湯の旅〜

実際の地図と線路で描いた九州の路線図（26駅）をすごろく盤にした、旅の手帖のようなインタラクティブマップ。**よりみちダイス**で1駅ずつ旅をしながら各駅の寄り道ノート・名産品・宿に出会い、お取り寄せ・宿の手配もでき、旅で貯めた**クラフト資金の出資**で駅の**トップオーナー**を目指す。写真のポストカード（**旅の便り**）を送り合い、配当・いいね・シェアで貯めた**クラフト資金**で列車を改造したりアバターを着せ替えたりできる体験型メディア（MVP）。

旧名は「よか旅すごろく九州」。フォルダ名 `yokatabi/`、localStorage のキー `yokatabi.kyushu.v1`、名前空間 `window.YT`、保存データの項目名（`acquired` など）は、遊んでいる人の保存データを守るため旧名のまま残している（画面・検索・共有に出る名前だけを変えた）。

このディレクトリ（`yokatabi/`）は、リポジトリ直下の Vite + React アプリとは**完全に独立した静的サイト**。ビルド工程はなく、ファイルをそのまま配信する。

## 1. North Star（すべての判断基準）

ユーザーが九州を **「気になる ➔ 購入する（お取り寄せ） ➔ 訪れる（旅行） ➔ 関係性がつづく」** の4段階でたどること。

| 段階 | プロダクト上の行動 | 記録先（localStorage） |
|---|---|---|
| 気になる | ダイスで駅に止まって寄り道手帖を読む（止まった日は `arrivals`） | `visited` |
| 購入する | 名産品物件のボタン（Amazon／楽天市場／Yahoo!ショッピング）を押す | `actions[id].product` |
| 訪れる | 宿泊・体験物件のボタン（楽天トラベル／じゃらん）を押す | `actions[id].stay` |
| つづく | 推し駅に登録する・旅の便り（写真）を投函する | `favorites`・`postcards` |

寄り道手帖の上部の「ジャーニー」表示は、この4段階の達成状況をそのまま映す。駅のオーナー権は、クラフト資金で出資した額（`purchases`。項目名は旧名のまま）のランキングで決まる（3章）。新機能を足すときは、どの段階を前に進める機能なのかを説明できること。

## 3. マネタイズと、出資ランキングのオーナー権（`js/ownership.js`・`js/owner.js`）

2026年10月の依頼で、**レシート（注文完了画面のスクショ）の提出・審査をすべてやめた**。オーナー権はゲームの中のクラフト資金だけで決まり、お買い物とは結びつけない。アフィリエイトのボタン（【PR】）は寄り道手帖にそのまま置くが、押してもご褒美はつけない（ジャーニーの「購入する／訪れる」を記録するだけ）。

### 3-1. 出資（`#owner-sheet` の出資届）
- 寄り道手帖のランキングの下の「クラフト資金で出資する」から。**その駅に停車中のときだけ**押せる（`Owner.canInvest`）。
- 出資届には、いまのトップオーナー・自分の順位・使えるクラフト資金と、「3位に入る／2位に入る／トップオーナー」の金額の札（`Ownership.needFor`。下克上ボーナス込みで、`meta.owner.investStep`（100万円）単位に切り上げ）。金額の欄と ±、ランキングの見込み（`Ownership.preview`）。
- 「出資して刻印する」：朱の風景印が押され（`Owner.sealSvg`）、`Store.spend` で資金を払い、`Ownership.register` に `{ via: 'funds', amount（万円） }` を足す。1位になったら王座交代の演出、それ以外は順位と配当のトースト。

### 3-2. 15秒覗くだけの急行切符ボーナス（`meta.peek`）
- 停車中の駅の名産品・宿のカードに『この駅の逸品を覗いて「三連ダイス超特急切符」を受け取る』（切符の線画つき）。押すとショップの検索ページを新しいタブでひらき（`preventDefault` しない）、**15秒**（`seconds`）たつと（その場で見えていれば即、別タブにいれば戻ったとき `visibilitychange`・`focus` で）特別切符 `ticket` とクラフト資金 `funds`（300万円、`ledger` の `peek`）を渡す。15秒より前に戻ったら「あと◯秒」の案内。**1駅につき1日1回**（`Store.peeks[id] = 'YYYY-MM-DD'`）。
- **アフィリエイト規約への配慮**：広告のリンクを押すことに見返りをつけると、Amazon アソシエイト・楽天アフィリエイト等の規約（インセンティブ付きのクリックの禁止）に触れるおそれがある（推定）。そのため覗くページは、`meta.peek.affiliate` が `false` のあいだは**紹介料のつかない普通の検索ページ**（`params`・`wrap` をつけない URL、`rel` に `sponsored` をつけない）。`true` にするのは、各サービスの規約で問題ないと確かめてから。
- 依頼の名前「かもめ超特急切符」は実在の列車名なので使わず、既存の「三連ダイス超特急切符」を渡す。

### 3-3. ランキングのしくみ（`YT.Ownership`）
- サーバーはないので、競う相手は `stations.json` の**ライバル旅人**（架空。`meta.rivals` の8人のうち、各駅の `rivals` に3人と金額（万円））。自分の行は `purchases[id]` の `scored` の合計。表示名は `profile.name`（空なら「あなた」）。レシート時代の記録（円）も、そのまま数に入れている。
- 並びは金額の大きい順。同じ額ならライバルが上。**1位＝トップオーナー**（地図の金の王冠・総資産額・称号・旅しおりの対象。`Ownership.sync()` が `acquired` に書き戻す）。
- **下克上ボーナス**：出資する時点で1位でなければ、出資額 × `meta.owner.upsetBonus`（1.3）を数える。
- **配当**：上位 `meta.owner.shareholders`（3）名に、駅の評価額（万円）× `meta.owner.dividendRates`（1位＝そのまま、2位・3位＝3割・1割5分）。配当はクラフト資金に入る（出資した資金は戻らない）。
- ライバルの額は固定なので、一度1位になれば抜き返されない（推定の設計）。

### 3-4. 守ること
- **ご褒美はゲームの中だけ**。順位・配当・クラフト資金・切符にお金の価値はない。
- 旧版の刻印（version 1）は `legacyStamps` に残している（画面には出さない）。手配中の記録 `pendingOwner` は読み込むと空にする。

- **技術スタック**：HTML5 / 自前の CSS / Vanilla JS / インラインSVG / CSS 3D / Web Audio API / IndexedDB。npm もビルドも不要（以前の Tailwind CDN はやめた）。
- **外部への依存は Google Fonts だけ**（2026年10月にスクショの文字読み取り（Tesseract.js）をやめた）。
- **スクリプトは classic script（`<script src>`）で読み込む。** ES Modules は `file://` で開くと CORS で止まるため使わない。モジュール間は `window.YT` 名前空間で受け渡す。読み込み順は `index.html` の末尾にある順のまま（icons は最初。craft → camera → map → dice → trip → ownership → photos → owner → garage → scenery → postcards → sharecard → game → app）。旅の便りのいいねもクラフト資金に入るので、`app.js` の起動では `Postcards.init` を最初の資金の計算より前に呼ぶ。
- **データ読み込み**：`fetch('stations.json')` を試し、`file://` や通信エラーのときは `window.YOKATABI_FALLBACK_DATA` を使う（`YT.Data.load()`）。フッターに「stations.json 読込済み／内蔵データで起動中」が出る。
- **効果音（`sound.js`）**：外部の音声ファイルは使わない。電子音のビープではなく、ノイズ＋フィルター＋倍音で、木のダイスが革のトレイで転がる「コロン」、レールの継ぎ目の「ガタン、ゴトン」（走った距離に合わせて鳴る）、駅メロ風のメジャーセブンスのアルペジオ（オルゴール／エレピ風・薄いディレイ）、刻印の「バン！」と弦のストロークのファンファーレ、工具の「カン」と和音の改造ファンファーレをつくる。AudioContext は最初のユーザー操作で作り、無音を一瞬鳴らして起こす。iPhone 対策として、`navigator.audioSession.type = 'playback'` と、別タブから戻ったときの 'interrupted' からの復帰を入れている。ミュートはヘッダーのボタンで、状態は保存する。

### 装丁「大人の旅手帖 ＆ クラシカル鉄道グラフィック」（2026年10月の全面改修）
プロの装丁家が仕立てた旅手帖と、19世紀の航海図・真鍮の路線図のような紙面。「AIが作ったようなチープさ」（絵文字・つるつるの単色の面・均一な角丸＋影のカード・塗り絵のような絵）を出さないことが決まり。トークンは `css/style.css` 冒頭の `:root`。新しい色を直書きせず、まずトークンを使う。

- **色**：紙 `--ivory #FAF6F0`・`--paper #FBF8F2`・`--antique #F4EFE6`、万年筆のインク `--ink #2C2523`、真鍮 `--brass #B8860B`・金線 `--gold #C59B27`・金箔 `--gold-leaf #D4AF37` `--gold-2 #E6C665` `--gold-3 #FAF0CA`、差し色は茜 `--akane #A8382B` だけ。罫 `--rule #C8B9A6`、ミシン目 `--perf #B8A68E`、駅名標の枠 `--plate #6E5D4F`。表紙は深緑 `--forest #234236`、車体の色に `--maroon` `--lacquer` `--porcelain`、胡桃 `--walnut #4A3525`。地図は海 `--sea #DFECEA`・陸 `--land #F3ECE1`。旧い名前（`--terracotta` `--mustard` など）は新しい色を指すようにしてある。
- **紙の質感**：`body::after` に `feTurbulence`（fractalNoise・0.8・4オクターブ）の粒子を `opacity: .04` で全面に重ねる（`--grain`）。各パネルの地にも `--fiber`。
- **箱**：角丸＋ドロップシャドウのカードは使わない。外枠1px＋内側に3pxあけた細線の飾り枠（`box-shadow: var(--frame)`、金なら `--frame-gold`）か、`mask` の `radial-gradient` で左右に硬券切符のパンチ穴（ダイスの欄・特別切符・乗車券・スポットライトの帯）。区切りはミシン目（`1px dashed var(--perf)`）。数字の帯は箱にせず、細い縦罫で区切る。影は、画面に重なるもの（モーダル・演出）の `--sh-3` だけ。
- **書体**：`--font-serif`＝Cormorant Garamond（数字・金額・欧文の見出し・駅番号。イタリックか600。数字はライニング数字にそろえる）、`--font-mincho`＝しっぽり明朝（駅名・見出し・ボタン・情緒の一文）、`--font-ui`＝Zen Kaku Gothic New（補助の小さな字。丸ゴシックは使わない）。大きな金額は `¥ 52,000,000` の欧文の組み（`app.js` の `yenFull`）。共通のクラス：`.ico`（線画）・`.num` `.num-it`（欧文の数字）・`.eyebrow`（欧文の小見出し）。
- **縦書き**：寄り道手帖の見出しは、左に縦書きの駅名標（`.eki-plate`：白い札にインクの二重の細枠、上に `No.07`）、右に情緒の一文（`tagline`）の縦書き（`.modal-tate`。スマホでは省く）。駅に着くと、映画のタイトルバックのような全画面のカットイン（`app.js` の `arrivalTitle`：縦書きの駅名と一文、約2秒、タップ・キーで飛ばせる）。
- **アイコン**（`js/icons.js`）：24×24 の方眼にパスだけで描いた、線 1.25px（`vector-effect: non-scaling-stroke`）の単色の線画。色は `currentColor`（インクか真鍮）。足すときは `P` に名前とパスを書く。塗る小さな点は「.」で始めるパス。
- **ダイス**：胡桃の立方体に、真鍮を彫り込んだ目と、茜の1の目。
- **スタンプ**：査収済のハンコ・風景印・ポストカードの消印は、二重の枠・日付の刻印・−6度の傾き・朱肉のかすれ（`Receipts.inkFilter`：`feDisplacementMap` で輪を揺らし、細かな粒で抜く。ハンコごとに seed を変える）。
- **演出**：原色の紙吹雪はやめ、金箔・真鍮のリーフが裏返りながらゆっくり舞い落ちる（`app.js` の `confetti`＝`.gold-leaf`、`game.js` の `goldRain`＝`.gm-rain`）。称号・王座交代・到着は、暗いベールに真鍮の細い罫と明朝・欧文のタイポグラフィ。
- **動き**：開閉・移り変わりは `var(--ease)`＝`cubic-bezier(.22, 1, .36, 1)`。跳ねる（y が 1 を超える）イージングと単調な linear は使わない。例外は、線路の流れる帯・航路の点線・風やカモメのように途切れずに流れる繰り返しだけ（linear のまま）。
- **ご当地の車窓**・**旅人たちのポストカードの絵**：銅版画（エッチング）の調子。生成りの紙に、インクの線と平行・斜めのハッチング、差し色は1色（`scenery.js` の `scene`、`postcards.js` の `illust`）。

- **使わないもの**：ネオン・発光・ギラギラした金枠・原色・ダーク基調のページ（暗いベールは演出のあいだだけ）。

- **タブ**：手帖の小口のインデックス4つ（線画のアイコン＋`01 / ROUTE MAP` すごろくマップ／`02 / LEDGER` オーナー刻印手帖／`03 / LOCOMOTIVE` 車両クラフト＆アバター／`04 / POSTCARD` 旅の便り＆フォト地図）。ひらいている章は紙の色で、上の縁に真鍮の帯。スマホでは番号と和文だけ（和文は `<wbr>` の位置で折り返す）。オーナー刻印手帖の中で「00 / 旅の巻頭言／オーナーの切手／マイ旅しおり」を罫で区切った札で切り替える（巻頭言は最初の栞。ひらいたときは切手）。タブの帯だけ画面上部に貼りつく。
- **車窓パノラマ**（`js/scenery.js`）：路線図の上に常設する高さ68pxの横長の窓。九州の観光列車の木の内装の雰囲気を借りた、ウォールナットの木目の窓枠と真鍮の二重細線（実在のデザイナーの名前は書かない）。中は銅版画の風景で、地域ごとに阿蘇の外輪山の稜線と噴煙／別府の湯けむり／海面とカモメ／夕暮れの街並み（低い太陽と窓の灯り）／森。奥の山並み・中景・手前の電柱と柵の3枚の帯を、列車の速さ（`Map.moveTrain` の `onSpeed` → `Scenery.setSpeed`）に合わせて別々の速さで流し（手前ほど速い）、ブレーキで景色もゆっくり止まる。帯は絵を「そのまま・左右反転」で並べて継ぎ目を消す。走行中は向かう駅の地域に切り替わり（重ねてふわっと入れ替える）、列車のまわりにもその地域のもの（生成り・真鍮・インクの細い線の粒）が浮かぶ。到着すると駅のまわりに大きめに浮かぶ。`prefers-reduced-motion` では動かさない。
- **ダイス**：CSS 3D の立方体（胡桃の木目、真鍮の目、茜の1の目）。振ると弾んで3軸に回り、約1.2秒で出目の面が正面に止まる。特別切符を使うとトレイに2〜4個並ぶ（`Dice.rollMany`）。止まった瞬間に金箔が舞い、地図に「〇マスすすむ！」の札、行き先の駅に波紋。
- **カード**：トップオーナーの駅は切手（ミシン目・県の色の細い二重枠・額面は Cormorant・風景印の消印・累計出資額・配当）。まだの駅は切手を貼る前の点線の空欄（自分の順位と、いまのオーナー）。称号は真鍮のメダリオン（旅人＝ブロンズ、開拓使＝銀、大名＝金、鉄道王＝金に茜）に線画のしるし。出資届は金の二重枠の証書（四隅に L 字の飾り罫）。ランキングは罫で区切った台帳の行。
- 幅 375px のスマホと PC の両方で崩れないこと（横スクロールを出さない、寄り道手帖の下のボタンは1行、出資届の見出しは1行）。

### 盤面のデザイン（`map.js`・`css/map.css`）：19世紀の航海図・真鍮の路線図
- **海**：`--sea #DFECEA` に細い平行線の模様（寄っても細かさが変わらないよう模様を縮める）、沖ほど淡い等深線4本、0.5°ごとの経緯線。盤面の縁に生成りの欄外と、10′ごとの墨と生成りの目盛りの帯。欄外の度数（`33°N` `130°E`、寄ると `33°30′N` や10′刻み）は Cormorant のイタリックで、カメラに合わせて付け直す。コンパスローズ（5°の目盛り・32方位の刻み・16方位の星・北だけ真鍮）と、帆船・蒸気船の細い線画。
- **陸**：`--land #F3ECE1` に、海岸線の内側の二重線。山地はごく淡い墨のぼかしとケバ（等高線に直交する短い刻み。`--lw` で縮む）。県境は一点鎖線、県名・山の名前は茶のしっぽり明朝、海の名前は浅葱。
- **重さ**：等深線と海岸線の内側の二重線は、海岸線を太く描くのではなく、ページを開いて手が空いたときに一度だけ距離の場を計算して細い線のパスにする（`buildShoreLines`。geo.js を作り直してもそのまま合う）。盤面全体のフィルタは使わず、模様と `<use>` の使い回しだけにする（駅が100を超えても重くしない）。
- **県名**（`PREF_LABELS`）：線路や駅とぶつからない各県の空き地に、**緯度・経度**で置く（重なるときは少しずらす。いまは周防灘・佐賀県をずらしている）。
- **駅**（`data-tier`）：主要駅（hub）は二重リングのあいだに県の色の細い輪と真鍮の菱形（訪れると菱形が真鍮で満ちる）、観光駅は白丸に墨の輪と上下の縦棒、ローカル駅は小さな白丸（訪れると中に県の色の点）。トップオーナーは金箔の円盤に真鍮の線画の王冠、共同株主は「株」の札。今いる駅・行き先の候補は細い輪がしっとり広がる波紋。
- **駅名標**：`<g class="station-label">` の中に、`#FAF6F0` の板に `#6E5D4F` の細枠のプレートと字（主要駅は二重枠）。字の幅は字数×字の大きさで見積もる。`labelDir` を活かす。LOD はこの `.station-label` の不透明度で出し分ける。
- **路線**（`ROUTE_STYLES`）：

| type | 見た目 | 割り当ての考え方 |
|---|---|---|
| `shinkansen` | 墨の二重線の中を真鍮の帯がゆっくり流れる | 九州新幹線・西九州新幹線の区間 |
| `trunk` | 墨と生成りが交互に並ぶ、昔の地図の鉄道記号 | 特急が走る幹線（鹿児島本線・日豊本線・長崎本線など） |
| `local` | 深緑に枕木の刻み | ローカル線（JR・第三セクター） |
| `scenic` | 茜の線に真鍮の点線 | 観光列車が走る路線（列車の商品名は書かず、路線名で示す） |
| `ferry` | 浅葱の破線 | 離島への航路 |
| `bus` | 茜の点線 | 鉄道がない区間のバス連絡（実際に鉄道がない区間を鉄道として描かない） |

- **区間のしるし**：真鍮の輪の札に、`YT.Icon.paths` の線画（`sparkle` `ferry` `bus`）。ライン制覇の金の路線は、金箔のグラデーションの帯がゆっくり明滅する（光のフィルタは使わない）。
- **カメラのボタン・地図の上の札**：真鍮の細い枠のプレートに線画のアイコンと明朝の字（倍率は Cormorant のイタリック）。ダイスの出目の札（`.dice-badge`）は左右にパンチ穴のある硬券の帯に茜の大きな数字、分かれ道の行き先（`.dir-btn`）は真鍮の二重細枠の方向板、スポットライト駅は真鍮の線のペナント。
- **列車**：絵文字ではなく、クラフト工房で選んだ車両の SVG（`YT.Craft.trainSvg` / `carriageSvg`）。経路の各区間の `<path>` を `getPointAtLength()` でなぞり、線路の向きに回して置く（左へ向かうときは絵を裏返して上下さかさまにしない）。2両目を連結していれば、1両目の約54単位うしろ（道のりの距離を遅らせた位置）を走る。1駅ずつ経由し、出発・到着で加減速、途中の駅の前ではゆるめ、走りながら小さく揺れる。煙突から選んだトレイル（綿雲・木の葉・湯けむり・星くず）がふわっと浮かぶ（停車中もときどき）。駅の少し手前で止まり、駅のしるしを隠さない。
- **スマホ**（幅639px以下）では、座標系は 800×960 のまま、表示する範囲（viewBox）だけ左右の海を少し切って九州を大きく見せる（`Map.fit()`）。

### 地図データ（`js/geo.js`）：実在の地理データから作る
海岸線・県境・山地・線路・駅を、実際の地図に合わせる。手描きの近似はしない。

- **作り方**：`bash tools/fetch-geo-data.sh <データのフォルダ>` で元データを取り、`node tools/build-geo.mjs <データのフォルダ>` で `js/geo.js` と各駅の `x`/`y`（stations.json）を作る。続けて `node tools/build-fallback.mjs`。元データは大きい（約100MB）のでリポジトリに入れない。
- **投影 `latLngToSvg(lat, lng)`**：北緯 30.15〜34.05°・東経 129.35〜132.05° が viewBox 800×960 に収まるよう、正距円筒図法（範囲の中央の緯度 32.1° で経度を cos 倍に縮める）で**縦横同じ倍率**に変換する。範囲の縦横比が盤面と違うので、縦をちょうどに合わせ、左右の余りは海として見せる（縦横を別の倍率で引き伸ばすと九州が横に太るため）。盤面1単位 ≒ 0.45km。`geo.js` の `proj` に定数を書き出し、`map.js` の `latLngToSvg` も同じ式を使う。屋久島・種子島もずらさず実際の位置に描く。
- **盤面に入る島だけ**：重心が盤面の外にある島（対馬・五島の西側など）は描かない。
- **海岸線・県境**：国土数値情報「行政区域（N03）」。県の輪を線分に分け、同じ県で2回出てくる線分（市町村の境）を消して県の外周を出し、2県に共通する線分を県境、残りを海岸線にする。Douglas-Peucker で間引く（海岸線 0.3 単位）。
- **山地**：標高タイル Terrain Tiles（Terrarium 形式・ズーム9、約260m格子）を並べ、少し均してから、400m・800m・1200m 以上のマスの外周をたどって等高線の輪にし（N03 と同じ「境の辺だけを残す」考え方）、Chaikin でなめらかにして間引く。阿蘇のカルデラは中が低いので、輪の内側が抜けて外輪山の形が出る。
- **線路**：下地の線路網は JR九州の路線だけ（`n02/` に国土数値情報「鉄道（N02）」の RailroadSection を置けばそれから、無ければ station_database の線形＝N02 を加工したもの）。すごろくの区間は `LEGS` に「路線コード・発駅・着駅」を並べ、実際の線路の上を最短でたどる（鳥栖・久留米・日田・立野・行橋・中津・延岡・都城・川内・諫早・早岐などを実際に通る）。バス・航路は通過点を経度緯度で書いて曲線にする（経路のイメージ）。
- **経由駅**（`WAYPOINTS`）：すごろくのマスではないが、路線の通り道の目印として小さく描く駅。位置は station_database の緯度経度。
- **駅**：`PLACES` に、鉄道駅は station_database の駅（緯度経度は駅データ.jp 由来）、旅のマス（黒川温泉・高千穂・屋久島・桜島）は代表地点の経度緯度を書く。JR 以外の鉄道の駅（太宰府＝西鉄、島原＝島原鉄道）は `NOT_JR` に入れ、下地の JR 線路網との距離は測らず、区間の線路との距離だけを測る。
- **路線の状況は、2026年7月の熊本の地震より前の状態で描く**（依頼による）。肥薩線（八代〜人吉〜吉松〜隼人）は全線を鉄道として通し、島原港〜熊本港の航路もある。
- **区間の組み方（26駅）**：博多〜熊本〜鹿児島中央は九州新幹線、熊本からは阿蘇（豊肥本線）・三角（三角線）・人吉（鹿児島本線で八代、肥薩線）・島原（有明海の航路＋バス）。佐賀から唐津・嬉野温泉・有田、有田から唐津・ハウステンボス。日田は博多〜由布院の久大本線の途中。霧島温泉は鹿児島中央（隼人経由）・宮崎（都城・吉都線経由）・人吉（肥薩線の矢岳越え、吉松経由）を結ぶ。桜島は鹿児島港からの航路。同じ線路を2つの区間がしばらく共有するところ（佐賀〜武雄温泉など）がある。
- **検証**：ビルドのたびに、鉄道の各駅と経由駅について「JR 線路網からの距離」「その駅から出る区間の線路からの距離」を測り、1単位（約450m）を超えたら失敗させる（いまは最大0.17単位）。
- **出典**：`geo.js` の `source` に書き、フッターに自動で出す。いまは「国土数値情報『行政区域（N03）』（国土交通省）を加工」「Terrain Tiles（Mapzen・AWS Open Data。SRTM・GMTED2010 は U.S. Geological Survey、ETOPO1 は NOAA 提供）の標高を加工」「station_database（CC BY 4.0。線形は国土数値情報『鉄道（N02）』を加工、駅の位置は駅データ.jp 由来）」。
- **配布元について**：国土交通省の配布元（nlftp.mlit.go.jp）にこの開発環境からは接続できなかったため、N03 は niiyz/JapanCityGeoJson の GeoJSON を使い、N02 は station_database の線形を使っている。配布元から取った N03 の GeoJSON（`n03/`）・N02 の RailroadSection（`n02/`）を置けば、そのまま読める（N02 は属性 N02_002・N02_004 を見る）。
- **重さ**：`geo.js` は約330KB（山地が約100KB）。点を増やすときは `simplify` の許容値で調整する。

### アフィリエイトURLの組み立て（`app.js` の `buildUrl`）

3. `wrap` があれば、`{url}` に組み立てたURLを入れてくるむ（例：楽天アフィリエイトの `https://hb.afl.rakuten.co.jp/hgc/<ID>/?pc={url}`、バリューコマース等）

### 盤面のカメラと3段階ズーム（`camera.js`・`map.js`）
- **カメラ**：`{cx, cy, z}`（盤面の中心と倍率 1.0〜4.0）を viewBox に変えて見せる。×1 は九州全体（スマホは左右の海を切った 584×960、PC は 800×960）。寄っているときだけ、端の駅も真ん中に来るよう海の余白ぶんはみ出せる。操作はホイール（カーソルの位置を中心に）・ピンチ・ドラッグ。ドラッグのあと 350ms は駅のタップを無視する（ドラッグ終わりで駅がひらかないように）。
- **なめらかさ**：viewBox を毎フレーム書き換えると重いので、アニメーションと指の操作のあいだは svg に CSS の transform をかけて動かし、止まったところで viewBox を確定する（`commit`）。逆スケールの付け直しも確定したときだけ。
- **右下のボタン**（`.cam-ctrl`）：現在地（×2.5）・九州全体（×1）・スポットライト駅・＋／−（線画のアイコンと字の真鍮の札）。スマホでは字を省いてアイコンだけ。
- **列車の追従**：ダイスを振ると今いる駅へ ×2.75〜3 で寄り（`Map.followStart`）、走るあいだは列車を画面の真ん中に保つ（`camera.follow`）。分かれ道では今いる駅と行き先の候補がぜんぶ入る倍率（×1.6〜3）に引いて止まり（`Map.frame`）、行き先ボタンはその倍率で置き直す。着いたら少し寄る（×1.18、最大 ×3.4。`Map.arriveZoom`）。指で地図を動かしたあとは、次にダイスを振るまで追従しない。
- **3段階ズーム（LOD）**：`svg.dataset.lod`（×1.55未満＝1、×2.45未満＝2、それ以上＝3）と、駅の `data-tier`（`stationTier`）で CSS が出し分ける。
  - LOD1：駅の点と線路だけ。駅名は hub と、今いる駅・スポットライト駅・トップオーナーの駅・行き先の候補だけ。山の名前・区間のしるし・地域の演出は隠す。
  - LOD2：tourist の駅名・地域の演出・区間のしるしも出す。
  - LOD3：すべての駅名と経由駅の名前。今いる駅の下に、寄り道手帖のひとこと（`tagline`）を出す。
- **逆スケール**：寄っても駅や字が巨大にならないよう、駅・字・山・札は `translate(x y) scale(z^-0.78)`、線の太さは CSS 変数 `--lw = z^-0.6` を掛け算（`calc(N * var(--lw, 1))`）、列車は `z^-0.6`。新しく線の太さを書くときも `calc(N * var(--lw, 1))` にする。
- **駅を増やすとき**は `stationTier` を必ず付ける（build-fallback.mjs が確かめる）。拠点を増やしすぎると LOD1 で字が重なるので、hub は県庁所在地・大きな乗換駅くらいにとどめる。

### 駅を追加するとき（100駅以上への拡張）
1. `stations.json` の `stations` に1件足す（`x`/`y` は仮の値でよい。`stationTier` も付ける）
2. 接続する駅の `connections` にも **お互いに** IDを書く
3. 新しい区間の `routeOverrides` に `type`・`name`・`minutes` を足す。離島は `type: "ferry"`
4. `tools/build-geo.mjs` の `PLACES`（駅の位置）と `LEGS`（区間がたどる路線）に足し、`node tools/build-geo.mjs <データのフォルダ>` で `x`/`y` と線形を作る（駅が線路から離れていれば失敗する）
5. `node tools/build-fallback.mjs` を実行する
6. 画面で、駅名・県名・経由駅の名前がぶつかっていないか確かめ、必要なら `labelDir`・`PREF_LABELS`・`WAYPOINT_QUIET` を直す

## 6. マイ旅しおり（トップオーナーの駅を巡る1泊2日のモデルコース）

North Star の「購入する → **訪れる**」をつなぐ機能。オーナー刻印手帖の中の「マイ旅しおり」でひらく（右側のミニ手帖のボタン・刻印の完了演出のボタンからも）。トップオーナーの駅が `meta.trip.minAcquired`（2駅）に届いた瞬間に一度だけ提案する（`tripPrompted`）。

- **生成（`YT.Trip.generate`）**：区間の `minutes` で全駅間の最短経路を出し、路線が変わるごとに `transferMinutes` を足す。1日目は gateway を `day1Start` に出発 → オーナーの駅を巡る → そのどこかに泊まる。2日目は泊まった駅で朝の過ごし方 → 巡る → gateway に `day2End` までに着く。時間内に収まる道順をすべて探して採点する（巡れる駅の数 ≫ 湯けむり物件に泊まる ＞ 評価額の合計 ＞ 移動の短さ）。候補は最大3プラン。入りきらない駅は正直に表示し、2日目が早く終わるときはまだオーナーでない近くの駅を「寄り道候補」に出す。
- **宿の比較**：このプランの宿泊地と、ほかの候補プランの宿泊地を並べ、楽天トラベル・じゃらんのボタンを置く。押すとジャーニーの「訪れる」を記録する（ご褒美はつけない）。出発日はしおりの表示用で、予約サイトのURLには渡さない。
- **保存**：localStorage の `itineraries` に道順（`seq`）だけを保存し、開くたびに最新データで旅程を組み立て直す。「旅の記録をリセット」では消さない。
- 道順の探索は、泊まる駅と巡る駅の組み合わせごとに一番点の高いものだけを残し、解散する gateway も一番点の高いものだけを数える（駅を増やしても速く終わるように。全26駅がオーナーでも約2秒）。
- 生成ロジックを変えたら `node tools/test-trip.mjs` を通す（全駅オーナーで3秒を超えたら失敗）。

## 7. 称号（トップオーナーの駅の資産の合計でランクアップ）

`meta.ranks` の順に **九州旅人（0円〜）➔ 九州開拓使（1億円〜）➔ 九州大名（3億円〜）➔ 九州鉄道王（5億5,000万円〜）**。総資産額（トップオーナーの駅の評価額の合計）で決まる。ライバルの額は固定なので、いまの仕組みでは減らない。

- ヘッダーの称号バッジ（押すとオーナー刻印手帖へ）と、手帖の「称号の道」。王座交代のたびに `checkRankUp` が比べ、上がっていたら演出のあと（約2.6秒後）に、縫い目のある紙の帯のカットインを重ねる。7秒で自動的に閉じ、クリック・Esc でも閉じる。出し終えた段階は `rankSeen` に保存する。
- しきい値や名前を変えるときは `meta.ranks` を編集する（`build-fallback.mjs` が検証）。

## 8. ゲームロジック

- **よりみちダイス**：出目 n の数だけ、列車が線路を進む（同じ移動の中で同じ駅は二度通らない）。行き止まりで残りがあれば、そこで止まる。止まった駅で `arrivals[id]` を今日にして、寄り道手帖をひらく。
- **オートナビ**（`app.js` の `planRoute`）：分かれ道で止まらない。出発の前に道のり全体を決め、分かれ道では、スポットライト駅までの駅数（通った駅を通らない BFS）がいちばん少ない路線を選ぶ（スポットライト駅へ通じないときは隣の駅の並びの先頭。推定の決め方）。人が選びたいときは、停車中に地図の分かれ道に出る**真鍮の進路の札**（次のダイスで届く分かれ道だけ。特別切符で振る数がふえると、届く範囲もふえる）をタップして路線を切り替える（`routeLocks`。オートナビと同じ路線に戻すとロックが外れる。通ったら外れる）。
- **走行の演出**（`map.js` の `moveTrain`）：経路をつないだ1本の SVG パスの上を、先頭車が `getPointAtLength` で向きを変えながら走り、2両目が同じ軌跡を少し遅れて追う。小さな上下の揺れ、煙突から白い蒸気のパフ、車体のうしろから真鍮の光の粒。頭上に「残り N 駅」の真鍮の札、通過した駅から金の波紋。途中の駅ではほんの少しゆるめるだけ。最後の駅の手前から `cubic-bezier(.22, 1, .36, 1)` の曲線でブレーキ（継ぎ目の音の間隔も開き、2打の間も伸びる）。止まると空気ブレーキの音。
- **到着の駅名標**：停車した瞬間に、画面の上から生成りの駅名標（駅番号・路線名・県、漢字の駅名、かな、乗ってきた路線の色の帯に前の駅と隣の駅）がカシャンと下りてきて、約4秒で戻る。初めての駅だけ、そのあと縦書きのタイトルバック（`arrivalTitle`）。
- **霧の解放**：まだ訪れていない駅は、地図でもフォトマップでも生成りの霧に沈んだ灰色（県の色も灰色）。初めて着いた駅は霧が晴れて真鍮の光の輪が広がり（`Map.unveil`）、以後は真鍮と県の色で灯る（フォトマップは投函した駅も）。
- **よりみち切符**：高級車両・連結車両（`ticket: true`）をひとつでもアンロックすると、1日3回まで、ダイスのあと出発する前に出目を −1／＋1 できる（1未満にはしない）。切符が使えるときは「nマス進む」を押して出発する。
- **駅を直接タップしても移動しない**：いまいる駅なら寄り道手帖。それ以外は**望遠鏡**の吹き出し（「◯◯駅（現在地から約nマス）｜いまのトップオーナー｜※ダイスを振ってこの駅に停車すると、寄り道手帖と現地スナップが解放されます」）。訪れたことのある駅は、吹き出しから手帖を閲覧だけできる。
- **指標**：九州踏破率＝訪問駅数／全駅、オーナー率＝トップオーナーの駅数／全駅、総資産額＝トップオーナーの駅の `assetValue` の合計（全26駅で10億5,500万円）、クラフト資金＝下の式。

## 9. クラフト経済（`js/craft.js`・`js/garage.js`）

- **クラフト資金**（`Craft.breakdown()`）＝ 発見ボーナス 200万円 × 初到着した駅の数 ＋ 配当の合計（`Ownership.totalDividends()`）＋ 旅の便りの地域発信ボーナス 1,000万円 × 投函した駅の数 ＋ 応援ボーナス 10万円 × 押した「素敵ね」の数 ＋ クリエイター評価配当 50万円 × 自分のポストカードに届いたいいねの数 ＋ 九州の魅力発信ボーナス 500万円 × シェアカードを発行・シェアした日数 − 使った額（`spent`）。0未満にはしない。残高は保存せず毎回計算する。総資産額は使っても減らない。
- **旅のゲームの入出金**：スポットライト駅のご祝儀・サプライズ・ハプニング・週末の大精算の観光収益（9-4）。
- **つり合いのための決めごと（推定）**：旅の便りは1駅1枚（投函し直すと差し替えで、ボーナスは最初の1回だけ）。自分のポストカードに届くいいねは、投函した直後に1〜3、そのあと約40分ごとに1つ、1枚につき最大20（`likeReceivedMax`）。シェアのボーナスは1日1回。
- **パーツ**（`meta.craft.train` / `avatar`）：車体フォルム＆塗装（6種）、2両目・連結車両（3種）、走行トレイル（4種）、帽子・頭（4種）、衣装（4種）、旅の相棒（3種）。各欄に0円の初期装備が1つ（`store.js` の `equipped` の初期値と同じID。`build-fallback.mjs` が検証）。アンロックするとすぐ装備する。
- **よりみち切符**：`ticket: true` のパーツ（高級車両・連結車両）を1つアンロックするごとに1日1枚増え、最大 `ticketMax`（3）枚。
- **絵**：列車（横から見た姿・1両は長さ120）とアバター（胸から上・viewBox 120×140、ヘッダー用は顔まわりを切り出し）は `craft.js` の SVG。マップの列車・ガレージのプレビュー・ヘッダーのアイコン・手帖のオーナー証・切手のカード・シェアカードで同じ絵を使う。
  - **列車**：側面の設計図のような精密な線画。塗装ごとに形を変える（気動車・前へ寝かせた運転台・流線形・蒸気機関車・二段屋根とアーチ窓・二段屋根と縦長の窓）。車体の色（深緑・ロイヤルマルーン・漆黒・白磁など）に、金線 `#C59B27` で窓枠・腰の帯・屋根の縁・唐草・台車と車輪。紋章はオリジナルの「楠の葉の丸紋」（二重の輪に三行脈の葉が三枚）。盤面では1両が約45pxなので、色の塊・窓の帯・車輪は太めにして、小さくても形がわかるようにする。実在の列車・会社のロゴ・紋章・車両の形の写しは描かない。
  - **アバター**：万年筆のインク線画の肖像（モノクロ＋差し色は茜の1色）。陰影は clipPath のハッチング（id は呼ぶたびに連番を付け、同じページに何枚並んでもぶつからない）。帽子4・衣装4・相棒3は線画で描き分け、ライバル旅人の設定でも同じ関数で描く。
  - **トレイル**：生成り・真鍮・金箔の色の、淡い粒と細い線（綿雲・金箔の葉・二重線の湯けむり・金の星）。
- **プレビューステージ**：銅版画のような細い線とハッチングの九州の風景（空・雲・山並み・噴煙の火山・高原・海・帆船・小さな駅）の前に、改造した列車（1両目＋2両目）が入線して減速し、ホームの先に停車して、加速して発車するのを繰り返す（停車中もときどきトレイル）。アバターがホームで待つ。パーツを替えるとすぐ絵が替わり、改造ファンファーレ（アンロック）・「カチッ」（付け替え）が鳴る。`prefers-reduced-motion` では停車した姿で止める。
- **パーツのカード**：硬券の切符（`var(--frame)`・左右の切り欠き・ミシン目・`No.01` の通し番号・Cormorant の値段）。装備中は朱の二重丸の判、ロックは錠のアイコンと「あと〇〇」。欄の見出しは線画のアイコンと `03-1 / LIVERY` のような欧文の通し番号。
- 全パーツの合計は約8億1,500万円。全26駅で1位になると配当だけで約10億5,500万円になるので、全部そろえるには多くの駅のトップオーナーになる必要がある。

## 9-4. 旅のゲーム（`js/game.js`・`meta.game`）
すごろくの「思わず声が出る」仕掛け。上品な旅の手帖のまま、演出はひとつずつ順番に出す（`#game-layer`）。止まった駅のあとの流れは **ピタ止め → 窓口の切符 → サプライズ（ワープ）→ 週末の大精算 → ライン制覇 → 寄り道手帖**（`Game.afterArrival`）。お金は `Store.ledger` に入出金として残し、`Craft.breakdown()` の `rewards`・`settle` に入る。
- **スポットライト駅**（`spotlight`）：いつも1駅（いまの駅から `minHops` 3マス以上）。半分の確率で「今週の旬」（地域テーマ）の駅から選ぶ。路線図の上に「スポットライト駅：〇〇駅まで最短あと〇マス！」、地図の駅に金のビーコンと真鍮のペナントの旗（盤面の上のふちの駅は旗を下に立てる）。ダイスで**ピタリと止まる**（通りすぎは数えない）と、一番乗りのご祝儀（`rewardMin`〜`rewardMax`、500万円きざみ）とレア切符1枚、金箔の舞とファンファーレ。続けてルーレットで次のスポットライト駅を決める。
- **特別切符の手札**（`deck`、最大 `deckMax` 5枚）：ダイスの欄の上に並び、押すと次のダイスで使う（`armed`）。二連（2個）・三連（3個）・四連クルーズ周遊（4個を3回つづけて、`cruiseLeft`）・ピタリ指定（1〜6を選ぶ。スポットライト駅までのマスを添える）。手に入れ方：止まった駅で20%（`arrivalTicketChance`）、ご祝儀（レアの中から）、ハプニング、工房の切符売り場（`price` のクラフト資金で）。ダイスはトレイに2〜4個並べ、少しずつずらして投げ入れ、「6＋6＝12！！」を大きく出す。よりみち切符（±1）はこれとは別で、合計の出目に使える。
- **ライン制覇**（`lines`、各駅はちょうど1つのラインに入る）：ラインの全駅で上位3名（共同株主以上）になると、そのラインの駅の自分の配当が `lineBonus`（2）倍（`Ownership.ranking`）。地図のそのラインの区間が金色に光り、はじめて制覇したときだけ「〇〇ライン完全制覇！！」の大きなスタンプ（`linesSeen`）。
- **週末の大精算まつり**：ダイスを `settleEvery`（7）回振るごとに1回（`settled`）。①オーナー・株主の駅の観光収益（その駅の自分の配当 × `tourismRate` 0.2）、②旅の便りに届いたいいね（前の精算のあとに届いたぶん × 50万円）を、ドラムロールのあとチャリン、チャリンとカウントアップし、ドカンと振り込む。いいねの配当は、この精算で振り込まれたぶんだけがクラフト資金に入る（`likesBanked`）。
- **旅のごほうびサプライズ／寄り道ハプニング**：止まった駅で `surpriseChance`（25%）。株主の駅の名物が海外で話題（評価額の6割）・投函したポストカードが観光ガイドの表紙に（2,500万円）・朝市のおみやげ（1,000〜2,000万円）・車掌さんから切符・名物のハシゴ（−300万円、でも切符をもらう）・桜島の上昇気流で好きな温泉駅へワープ（その駅に止まったことになる）。
- **王座奪還**：出資で1位を追い越したとき、手帖を閉じて地図を見せ、前のオーナーの王冠が稲妻でパリンと割れ、自分の王冠とアバターが地図の駅にドスンと刺さる → ライン制覇 → 王座交代のお祝い。
- 効果音（`sound.js`）：`jackpot`・`drumroll`・`charin`・`dokan`・`tick`・`surprise`・`oops`・`shatter`・`thud`。

## 9-2. 旅の便り＆マイフォト地図（`js/postcards.js`・`04 / POSTCARD` のタブ）
- **投函**：駅をプルダウンで選んで（ダイスでその駅にいなくてよい）、写真と一言（60文字まで）を送ると、白い枠のポラロイド（駅の風景印・アバターと旅人名・しっぽり明朝の一言）になる。写真は長い辺 1000px の JPEG にして IndexedDB に保存し、どこにも送らない。差し替えた古い写真は消す。
- **わたしの九州フォトマップ**：盤面と同じ地図（`geo.js`）を淡く描き、投函した駅に写真の小さなポラロイドのピンがぷかぷか浮かぶ。ピンか下のカードをタップすると、地図のその駅に金の波紋が広がり、拡大ポストカード（いいねの数・クリエイター評価配当・いいねをくれた旅人）がひらく。すごろくマップと同じカメラ（`YT.Camera`）で、ズーム・パンできる。
- **写真ピンの束ね（クラスタリング）**：画面の上で 56px より近いピンは、重ねたポラロイドの束「（カメラの線画）×N枚の思い出」にまとめる（×3.9 以上では束ねない）。束をタップすると、いちばん近い2枚が離れる倍率まで寄ってほどける。倍率が変わったときだけ組み直す。ピンと束は、地図の幅が狭いときは大きくして（最大1.8倍）画面で約40pxを保つ。フォトマップの範囲は `100 -60 620 1020`（北の駅のピンが上で切れないよう、上に海を足している。`PM_BASE` と同じにする）。
- **旅人たちのポストカード**：`stations.json` の `postcards`（架空の旅人・イラスト）。ダイスでその駅に止まったことがある（いまいる駅を含む）ときだけくっきり見えて「素敵ね」を押せる（ハートが舞う）。まだの駅は `blur(10px)` のすりガラスに「◯◯駅に停車すると閲覧できます」。寄り道手帖の「現地スナップ」にも、その駅の便りを出す。

- **切手と消印**：投函する写真は、Canvas（`Postcards.stampCanvas`）で生成りの台紙の上のアンティークの切手（白い縁に目打ちの半円のギザギザ・内側の細い二重の枠）に仕立て、右下に朱肉（`#A8382B`）の「駅名＋日付＋九州よりみち」の丸い消印と波線を、−6度傾けてかすれさせて押した JPEG にして保存する。ポラロイドでは縁が切れないよう全体を見せる。投函のボタンは『この景色を、次の旅人の手帖へ託す』、添え字は「あなたの1枚が、誰かの次の旅の行き先になります」（「目的地」は使わない語なので「行き先」に言い換えた）。
- **ある旅人から届いた記憶**：ダイスで止まった駅に、まだ受け取っていない旅人たちの便り（架空）があれば、到着のあと右下からポラロイドがすっと届き、閲覧ボーナス `meta.craft.memoryBonus`（100万円、`ledger` の `memory`）が入る。1通につき1回（`memories`）。タップか約5秒で消える。
- **霧の解放**：フォトマップのまだの駅は霧の灰色、到着・投函した駅は真鍮の輪と県の色（8章）。
- **巻頭言**：初回の表紙（革張りの手帖の扉。『よりみちの旅をはじめる』）・マップ右上の直径32pxの真鍮の羅針盤（巻頭言と、灯した踏破駅・手帖に綴じた記憶（自分の便り＋旅人たちの便り）の数）・手帖の「00 / 旅の巻頭言」の栞（縦組み）の3か所。文面は `app.js` の `PREFACE`。署名は「九州を愛する旅人たちの手帖」。

## 9-3. 手帖シェアカード（`js/sharecard.js`）
- ヘッダーの「手帖カード」、フォトマップの「手帖カードをシェア」から、1200×630 の硬券切符・手帖の見開き風の1枚絵を `<canvas>` だけで描く（外部のサーバーは使わない）。
  - 紙：生成りに Canvas で描いた粒子・繊維・ふちの焼け。外枠1px＋内側の細線の二重枠、四隅の丸い切り欠きと、地図の半券を分けるミシン目の半円。まわりは深緑のクロスの表紙がパンチ穴からのぞく。
  - 左：古地図の調子の九州（海のハッチングと等深線、海岸線の内側の二重線、経緯度・図郭の目盛り・コンパスローズ・縮尺）。まだの駅は白抜き、踏破した駅は茜、トップオーナーの駅は真鍮の二重リングに金箔の菱形と駅名標、投函した駅は金箔の糸でつないだポラロイド。その右に、オーナーの駅（なければ今いる駅）の地域テーマから選んだ縦書きの一文と日付。
  - 右：`01 / ROUTE MAP` `02 / LOCOMOTIVE` `03 / LEDGER` の欧文の見出し、愛車編成（1両目＋2両目）を彫り線の車窓の枠に、アバターを真鍮の楕円の枠に。旅人名・**二つ名**（オーナーの駅の地域テーマ・投函した県の数・装備から自動で選ぶ）・総資産額（`¥ 256,000,000`）・踏破率・投函したスナップ・トップオーナーの駅。
  - 右下に、朱肉のかすれ・二度押し・−6度の風景印（「Q-TRIP KYUSHU OFFICIAL TRAVELBOOK」・日付）と公開URL。
- 車両とアバターは SVG を画像にして描く（SVG の中で外部のものを読まないこと。書体は Canvas 側で `document.fonts.load` してから描く）。
- **保存**：`toDataURL('image/png')` でダウンロード。**シェア**：`navigator.canShare({ files })` が使えるとき（スマホ）は画像つきで共有シート、使えないとき（PC）は画像を保存して X の投稿画面（`twitter.com/intent/tweet`）を別タブでひらく。発行かシェアで、1日1回だけ九州の魅力発信ボーナス。

- 画面に見える文にもアプリ名を入れる（ヘッダーの h1、「あそびかた」の一文、フッター）。
- **公開URLを変えるとき**は、`<head>` のブロックの URL（canonical・og:url・og:image・JSON-LD の url と image）をまとめて書き換える。
- `og.jpg` は、まっさらな状態の盤面のスクリーンショットに表紙とロゴを重ねて作った画像。盤面やロゴを大きく変えたら作り直す。

## 12. デプロイ

- **公開URL：`https://q-trip.github.io/`**（GitHub の組織 `q-trip` のリポジトリ `q-trip/q-trip.github.io`。既定のブランチ `main` に置いたファイルがそのまま公開される）。

## 13. コーディング規約

- 依存ライブラリを増やさない（Google Fonts のみ）。地図の元データはビルド時にだけ使い、ページは `js/geo.js` だけを読む。
- 文字列を HTML に差し込むときは必ず `esc()` を通す（データは自前でも、将来の外部データ化に備える）。
- 画面の文言は日本語（欧文は2章の決まりの範囲だけ）。絵文字は使わず、`YT.Icon` の線画を使う。コメントも日本語で、ねらい（なぜそうするか）を書く。
- 開閉・移り変わりは `var(--ease)`。新しい箱は `var(--frame)` かパンチ穴で、角丸＋影にしない。
- アニメーションは `prefers-reduced-motion` で弱める（`style.css` の末尾。ダイスは短く、列車は速く、トレイルは出さない）。
- キーボードで操作できること：駅ノードは Tab で選べて Enter で動く。モーダル・出資届・巻頭言・演出は Esc で閉じる。進路の札は Tab で選べて Enter で切り替わる。
