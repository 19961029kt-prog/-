# Claude Codeを自分好みに改造できる「Mods」入門

2026年10月1日、AnthropicはClaude Codeの新しい仕組み「Mods（モッド）」を発表しました。Modsを使うと、Claude Codeの見た目や動き方を、自分の使い方に合わせて変えられます。

この記事では、プログラミングに詳しくない人向けに、Modsでできることと、安全な使い始め方を紹介します。コードの書き方には踏み込まず、「入れる・確かめる・止める」に絞って説明します。

## Modsってなに？

Modは、Claude Codeに機能を足したり、動きを変えたりする小さなプログラムです。プラグインの一種として配られ、中身はJavaScriptやTypeScriptで書かれています。

できることの例を挙げます。画面の横にパネルを出したり、入力欄の上に帯を表示したりできます。

Claude Code自身の表示を描き替えることもできます。さらに、AIがツールを使う直前に割り込んで確認を挟んだり、AIを通さずにすぐ動く独自のコマンドを足したりもできます。

ほかにも、Modの中の処理どうしでデータを受け渡せます。たとえば、ツールを使った回数を数えて、画面に表示するといった使い方です。

## 使える場所と、必要なバージョン

Modsは、ターミナルで使うClaude Codeと、デスクトップアプリのCodeタブで動きます。ターミナルではv2.1.287以降、デスクトップアプリではv2.1.286以降が必要です。

バージョンは、ターミナルなら `claude --version` で確かめられます。Modは標準でオンになっているので、新しい版なら特別な設定はいりません。

なお、VS Codeの拡張機能やクラウドのセッションでは、Modの処理は動きますが、画面には何も描かれません。パネルなどの見た目を楽しみたいなら、ターミナルかデスクトップアプリで使いましょう。

## まず試したい「You should know」

最初の1つにおすすめなのが、標準で入っている「You should know」です。長めの仕事をAIに任せている間、横で見守る補助役が動き、見落としそうな大事なことを入力欄の上にメモで知らせてくれます。

このModは、最初は無効になっています。Claude Codeを開いて、次の1行を入力すると有効になります。

```
/plugin enable cc-plugin-you-should-know@builtin
```

公式ドキュメントには「組織で使える場合に一覧に表示される」とあり、環境によっては出てこないこともあるようです。【未確認：出てこない具体的な条件は、公式資料では確認できませんでした】

## Modを入れる・確かめる・止める

ほかの人が作ったModは、マーケットプレイスと呼ばれる配布場所から入れます。Claude Codeの中で `/plugin install 名前@配布場所` と打つのが基本です。

入れたあとは、`/plugin` と打つと、読み込まれたModの数と名前が表示されます。「入れたのに動かない」と思ったら、まずここを確認しましょう。

止めたいときは、`/plugin` のInstalledタブから、そのModを無効にします。自分で入れたModを1回だけまとめて止めたいときは、`claude --safe-mode` で起動します。

ただし、`--safe-mode` では標準で入っているModは止まりません。逆に、ほかの自分用の設定もまとめて止まるので、困ったときの切り分け用と考えてください。

公式のサンプルには、コンテキストの埋まり具合を天気予報のように表示する「token-weather」もあります。長い仕事で「そろそろ限界かも」が目で見えるので、試してみる価値があります。

ただし、サンプルはサポート対象外として公開されているものです。通常のインストールとは入れ方も違うので、公式ドキュメントの手順を読み、中身を確かめてから使いましょう。

## いちばん大事な注意：Modはあなたと同じ権限で動く

Modは、守られた箱の中で動くわけではありません。あなたのパソコンのファイルを読み書きしたり、ネットに通信したり、APIキーなどの秘密情報を読んだりできます。

だから、知らない人が作ったModは入れないでください。公式や、信頼できる作者・配布場所のものだけを使うのが鉄則です。

入れる前に中身を確かめる方法もあります。Modのファイルを手元に用意して `claude plugin validate ./フォルダ名` を実行すると、そのModが何をするのかを、動かさずに一覧で確認できます。

会社のTeamプランやEnterpriseプラン、管理者が設定を配っているパソコンでは、「sec-default」という見張り役のModが先に読み込まれます。これが、ユーザーが入れたModに、禁止ルールや組織が管理する設定を勝手に上書きさせないようにしています。

ただし、見張り役が守るのはその範囲だけです。それ以外の危ない動きまで止めてくれるわけではないので、信頼できるModだけを入れる、という鉄則は変わりません。

## まとめ

Modsは、Claude Codeを「使う道具」から「自分で育てる道具」に変える仕組みです。まずは標準の「You should know」を有効にして、Modがどんなものかを体験してみてください。

慣れてきたら、Claude Codeに「こういう表示が欲しい」と話して、Modを作ってもらうこともできます。ただし、どんなModも、信頼できるものだけを入れることを忘れないでください。
