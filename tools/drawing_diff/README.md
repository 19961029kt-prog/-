# drawing_diff — 図面PDF 視覚差分ツール

旧版と新版の図面 PDF を**ピクセル単位**で比較し、変更点を色分けして出力します。
CAD から出力した**超長尺・極小文字のベクター図面**（例: 3200mm × 85mm、文字 0.7pt、線 6 万本）と、
**スキャン図面**（画像だけの PDF。ズレ・傾き・汚れあり）の両方に対応します。

| 色 | 意味 |
|---|---|
| 🔴 赤 | **削除**: 旧版にだけある線・記号 |
| 🔵 青 | **追加**: 新版にだけある線・記号 |
| ⬜ 薄いグレー | 変更なし（両方にある） |
| 🟧 橙の枠 + 番号 | 変更箇所（近い差分をまとめた単位）。座標・文字の変更内容は CSV に出力 |

## ブラウザ版（インストール不要・チーム共有用）

<https://19961029kt-prog.github.io/-/drawing-diff.html>

URL を開いて旧版と新版の PDF を選び、「比較する」を押すだけで使えます。処理はすべてブラウザ内で行うので、図面がサーバーに送られることはありません。

- 推奨ブラウザ: Chrome または Edge（PC）
- 変更箇所一覧の行をクリックすると、その場所を高解像度で描き直した**拡大図**（差分 / 旧版 / 新版を切り替え）が表示されます
- 本体は `drawing-diff.html`（リポジトリ直下）。PDF の読み込みには同梱の pdf.js（`public/vendor/pdfjs-3.11.174/`、日本語フォント用の文字コード表を含む）を使います

複数ページの一括処理や、拡大図付きの PDF レポートが欲しい場合は、以下の Python 版を使ってください。

## 1. インストール

Python 3.9 以上が必要です。

```bash
pip install pymupdf opencv-python-headless numpy
```

## 2. 実行手順

```bash
python drawing_diff.py old_drawing.pdf new_drawing.pdf -o diff_out
```

出力（`diff_out/`）:

- `diff_result.pdf` — 全体図（元図面と同じ用紙サイズ）＋ **変更箇所ごとの拡大図ページ**（差分 / 旧版 / 新版を並べた A4 横）
- `diff_p001.png` … — ページごとの全体図
- `details/p001_001.png` … — 変更箇所ごとの拡大図
- `changes.csv` — 変更箇所の一覧（ページ、番号、種別、mm 座標、文字・注記の変更内容）。Excel でそのまま開けます

主なオプション:

```bash
python drawing_diff.py old.pdf new.pdf -o out --pages 1,3-5   # 一部のページだけ比較
python drawing_diff.py old.pdf new.pdf -o out --kind cad       # 図面の種類を指定（auto / cad / scan）
python drawing_diff.py old.pdf new.pdf -o out --dpi 1200       # 解像度を指定（既定は自動）
python drawing_diff.py old.pdf new.pdf -o out --no-text        # 文字情報での比較をしない
python drawing_diff.py -h                                      # 全オプション
```

動作確認用のサンプル（ズレ・傾き・ノイズ入りのスキャン風 PDF）を作るには:

```bash
python make_sample.py -o samples
python drawing_diff.py samples/old_drawing.pdf samples/new_drawing.pdf -o out
```

## 3. 処理の流れ

1. **図面の種類と解像度を決める** — ページの大半が画像ならスキャン図面、そうでなければ CAD 図面と判定します。

   | 種類 | 自動で決まる解像度 | 理由 |
   |---|---|---|
   | CAD（文字情報あり） | 600dpi | 文字の変更は文字比較で拾うので、線・記号が確実に見える解像度で十分 |
   | CAD（文字が線で描かれている） | 1200dpi | 極小文字も画素で比べる |
   | スキャン | 300dpi | |

2. **位置合わせ** — 新版を旧版に重ねる変換（平行移動・回転・倍率）を求めます。
   - CAD 図面: 両方の版に 1 回だけ出てくる文字列（キロ程・機器名など）の位置から求めます（RANSAC）。1 画素未満の精度です
   - スキャン図面・文字のない図面: 線画どうしの距離が最小になる位置を、粗い画像から細かい画像へ探します（チャンファーマッチング）
   - 半画素未満のズレしかなければ「ズレなし」とし、許容幅を最小（1px）にして比べます
3. **タイルごとの差分** — ページを区画に分けて高解像度で描き、「相手側の許容幅以内に線があれば同じ」とみなして削除・追加を求めます。新版は位置合わせの変換をかけて直接描くので、画像を変形するときのにじみが出ません。黄・水色などの色線も線として扱います。
4. **ノイズ除去** — 開処理と小面積成分の除去で、スキャンのゴミ点を消します（スキャン図面のみ）。
5. **文字の比較**（文字情報を持つ PDF）— 文字列と位置を突き合わせ、`「8k427」→「8k437」` のように変更内容を記録します。極小の文字でも確実に拾えます。
   **注記の比較** — PDF ビューアで書き込んだ手書き・図形・付箋・スタンプなどの注記は、図面本体とは別に保存されています。種類と位置を突き合わせ、点 1 個のような小さな書き込みも「注記追加: 手書き」として確実に拾います。
6. **まとめと出力** — 近い差分を 1 つの変更箇所にまとめ、全体図は細かい差分が消えないよう「1 画素でもあれば残す」方式で縮小します。変更箇所ごとに、最大 2400dpi で描き直した拡大図を作ります。

## 4. パラメータ調整ガイド

CAD 図面は自動設定でそのまま使えることがほとんどです。以下は主にスキャン図面向けです。

| 症状 | 原因 | 対処 |
|---|---|---|
| **全体の線が赤と青の二重線になる** | 位置合わせの失敗 | ログの `位置合わせ:` 行を確認します。図面の種類の判定が違っていれば `--kind` で指定します |
| 線の縁に沿って細かい赤・青が点々と出る | 残ったズレ、線幅の違い | `--tolerance` を 4〜6 に上げます |
| ゴミ点や汚れが差分として拾われる | スキャンノイズ | `--min-area` を 50〜150 に、`--open-kernel` を 3 に上げます |
| 小さな変更（短い線や点、文字 1 字）を見逃す | フィルタが強すぎる・解像度不足 | `--tolerance 2`、`--min-area 10`、`--open-kernel 0` に下げます。必要なら `--dpi 400` も |
| 薄い線や鉛筆書きが消える | しきい値が低い | `--threshold 200` 前後を指定します（値が大きいほど薄い線を拾います） |
| 背景の地紋や網掛けが全部線扱いになる | しきい値が高い | `--threshold 120` 前後に下げます |
| 枠が細かく分かれすぎる / 大きくまとまりすぎる | まとめる距離 | `--cluster` を上げると統合、下げると分割します |
| メモリ不足、または処理が遅い | 画素数が多い | `--dpi` を下げます |

`--tolerance`・`--min-area`・`--open-kernel`・`--cluster` の px は 300dpi 基準で、解析解像度に合わせて自動で換算されます。

## 5. 制約

- ページ同士を対応させるため、旧版と新版のページの並び順が同じである必要があります。ページ数が違う場合は、共通のページ数分だけ比較します。
- 線の色だけが変わった場合（例: 黒 → 赤）は検出しません。
- 位置合わせはページ全体で 1 つの変換を推定します。スキャン時に紙が局所的に歪んだ場合は、一部に二重線が残ることがあります。その場合は `--tolerance` を上げて対応します。
- ブラウザ版の処理時間の目安（4 コアの PC）: 3200mm × 85mm の CAD 図面（600dpi）で約 25 秒、A0 相当のスキャン図面（300dpi）で約 20 秒。
