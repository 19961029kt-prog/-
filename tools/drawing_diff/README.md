# drawing_diff — 図面PDF 視覚差分ツール

OCR 化されていない（テキスト情報を持たない）図面 PDF の旧版と新版を**ピクセル単位**で比較し、
変更点を色分けして出力します。

| 色 | 意味 |
|---|---|
| 🔴 赤 | **削除**: 旧版にだけある線・記号 |
| 🔵 青 | **追加**: 新版にだけある線・記号 |
| ⬜ 薄いグレー | 変更なし（両方にある） |
| 🟧 橙の枠 + 番号 | 変更箇所（近い差分をまとめた単位）。座標は `changes.csv` に出力 |

## 1. インストール

Python 3.9 以上が必要です。

```bash
pip install pymupdf opencv-python-headless numpy
```

GUI 付きの OpenCV が既にある環境なら `opencv-python` でも動きます。poppler などの外部ツールは不要です。

## 2. 実行手順

```bash
python drawing_diff.py old_drawing.pdf new_drawing.pdf -o diff_out
```

出力（`diff_out/`）:

- `diff_result.pdf` — 全ページの差分画像を元図面と同じ用紙サイズでまとめた PDF（拡大しても線が潰れません）
- `diff_p001.png` … — ページごとの差分画像（300dpi）
- `changes.csv` — 変更箇所の一覧（ページ、番号、種別[追加/削除/変更]、px と mm の座標）。Excel でそのまま開けます

主なオプション:

```bash
python drawing_diff.py old.pdf new.pdf -o out --pages 1,3-5   # 一部のページだけ比較
python drawing_diff.py old.pdf new.pdf -o out --dpi 400        # さらに高解像度で処理
python drawing_diff.py old.pdf new.pdf -o out --save-masks     # 調整用の中間画像も保存
python drawing_diff.py -h                                      # 全オプション
```

動作確認用のサンプル（ズレ・傾き・ノイズ入りのスキャン風 PDF）を作るには:

```bash
python make_sample.py -o samples
python drawing_diff.py samples/old_drawing.pdf samples/new_drawing.pdf -o out
```

## 3. 処理の流れ

1. **ラスタライズ** — PyMuPDF で 300dpi のグレースケールに変換します。巨大な図面は `--max-pixels`（既定 4 億画素）を超えると dpi を自動で下げ、警告を出します。
2. **二値化** — ガウシアンぼかし（`--blur`）の後、Otsu 法で線・記号（インク）を抽出します。紙の地色やスキャンの濃淡むらはここで消えます。
3. **位置合わせ** — 新版を旧版に重ねるため、ECC（画像相関の最大化）で回転と平行移動を推定します。粗い画像で推定してから細かい画像で詰める 2 段階です。失敗した場合は ORB 特徴点 + RANSAC に切り替えます。
4. **許容幅付き差分** — 「相手側の半径 `--tolerance` px 以内に線があれば同じ」とみなします。位置合わせ後に残る数 px のズレや、線幅の違いはここで吸収されます。
5. **ノイズ除去** — 開処理（`--open-kernel`）と小面積成分の除去（`--min-area`）で、スキャンのゴミ点を消します。
6. **まとめと出力** — 近い差分（`--cluster` px 以内）を 1 つの枠にまとめ、番号を振って合成します。

## 4. パラメータ調整ガイド

まず `--save-masks` を付けて実行し、`removed_pNNN.png` / `added_pNNN.png`（差分のみ）と
`new_aligned_pNNN.png`（位置合わせ後の新版）を確認すると、原因を切り分けやすくなります。

| 症状 | 原因 | 対処 |
|---|---|---|
| **全体の線が赤と青の二重線になる** | 位置合わせの失敗 | ログの `位置合わせ:` 行を確認します。`failed` なら `--align orb` を試します。スキャンで縮尺がわずかに違うなら `--motion affine`。精度を上げるなら `--align-max-side 5000` |
| 線の縁に沿って細かい赤・青が点々と出る | 残ったズレ、線幅の違い | `--tolerance` を 4〜6 に上げます |
| ゴミ点や汚れが差分として拾われる | スキャンノイズ | `--min-area` を 50〜150 に、`--open-kernel` を 3 に上げます |
| 小さな変更（短い線や点、文字 1 字）を見逃す | フィルタが強すぎる | `--tolerance 2`、`--min-area 10`、`--open-kernel 0` に下げます。必要なら `--dpi 400` も |
| 薄い線や鉛筆書きが消える | 二値化の閾値が低い | `--threshold 200` 前後を指定します（値が大きいほど薄い線を拾います）。`--blur 0` も試します |
| 背景の地紋や網掛けが全部インク扱いになる | 二値化の閾値が高い | `--threshold 120` 前後に下げます |
| 枠が細かく分かれすぎる / 大きくまとまりすぎる | クラスタ距離 | `--cluster` を上げると統合、下げると分割します |
| 共通部分が濃くて差分が見にくい | 表示設定 | `--common-alpha 0.4` で薄くします（0 で非表示） |
| メモリ不足、または処理が遅い | 画素数が多い | `--dpi 200`、または `--max-pixels 200000000` |

目安: px の値は dpi に比例します。dpi を 2 倍にしたら `--tolerance`・`--cluster` は 2 倍、`--min-area` は 4 倍にすると同じ効き方になります。

## 5. 制約

- ページ同士を対応させるため、旧版と新版のページの並び順が同じである必要があります。ページ数が違う場合は、共通のページ数分だけ比較します。
- 位置合わせはページ全体で 1 つの変換を推定します。スキャン時に紙が局所的に歪んだ場合（たわみ・波打ち）は、一部に二重線が残ることがあります。その場合は `--tolerance` を上げて対応します。
- 図面全体が移動した（レイアウト変更・用紙サイズ変更など）場合は、位置合わせで吸収できる範囲（ページ寸法の 30% 以内のズレ、±25% 以内の縮尺差）を超えると無補正で比較します。
